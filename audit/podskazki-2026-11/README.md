# Подсказки Яндекса и Google, ноябрь 2026

Сбор для расширения блога: какие справочные темы ищут и каких статей на сайте нет.

- `crawl.py`: первый сбор, 81 затравка (затравка, + буква, + уточнение), Яндекс по всей России и Google.
- `crawl2.py`: второй сбор, ещё 130 затравок и второй уровень по 700 лучшим фразам первого.
- `raw.jsonl.gz`: сырые ответы, 29 094 запроса к подсказкам, 55 205 уникальных фраз. Перед повторным разбором распаковать в `raw.jsonl` рядом со скриптами.
- `analyze.py`: чистка (города, магазины, коммерческие, другие значения слов, тема fanline) и сверка со статьями сайта.
- `plan_xlsx.py`: контент-план по темам, собирает `podskazki-plan-statey.xlsx`.
- `proverit-v-wordstat.txt`: 101 главная фраза по темам плана для Вордстата (составлен вручную).
- `prompt-claude-chrome-wordstat.md`: промпт для Claude в Chrome со списком: частоты и выгрузка «Топ запросов» по каждой фразе.

«Вес темы» в плане считается по позиции и повторяемости фраз в подсказках. Это не частота запросов.

## Что сделано по точным ключам

- `klyuchi-po-stranicam.json`: какие ключи Вордстата на какую страницу (`pages[url]["add"]`), частоты в `keys`.
- 39 новых статей: `dostavka-src/data/longreads_ws2.py`, `longreads_ws2b.py`, `longreads_ws2c.py`, `longreads_ws2d.py`.
- Дописки к 52 существующим страницам: `dostavka-src/data/wordstat_cover2.py` (разделы и вопросы в конец страницы), страница ливнёвки правится руками.
- Ключи «сваи жби» ушли на товарную страницу `/dostavka/svai-zhbi/`, а не в отдельную статью, чтобы страницы не спорили за один запрос.
- Реестр `audit/klyuchi-tochnye.json`: страница и её ключи. Группа 34 в `audit/_verify.py` проверяет, что каждый ключ стоит на странице подряд, слово в слово (между словами только запятая, кавычки, скобки).
- `audit/_unique.py`: повторы авторского текста с остальными страницами сайта (фрагменты по 5 слов, порог 5%) и штампы. Уникальность по интернету этой проверкой не меряется, для неё нужен text.ru или Advego.

## Третья партия для Вордстата

- `select3.py`: отбор из базы подсказок справочных фраз, которых нет на сайте дословно и которые ещё не проверялись (партии 1, 350 и 2). Мусор вычищается регуляркой, партия раскладывается по темам: одна фраза на тему, 400 самых весомых тем.
- `proverit-partiya3.txt`: 381 фраза после ручной чистки (убраны «пгс это специальность», «цоколь для лампы», темы скважины и т.п.).
- `prompt-claude-chrome-wordstat-partiya3.md`: промпт для Claude в Chrome с этим списком.
