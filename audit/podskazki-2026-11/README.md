# Подсказки Яндекса и Google, ноябрь 2026

Сбор для расширения блога: какие справочные темы ищут и каких статей на сайте нет.

- `crawl.py`: первый сбор, 81 затравка (затравка, + буква, + уточнение), Яндекс по всей России и Google.
- `crawl2.py`: второй сбор, ещё 130 затравок и второй уровень по 700 лучшим фразам первого.
- `raw.jsonl.gz`: сырые ответы, 29 094 запроса к подсказкам, 55 205 уникальных фраз. Перед повторным разбором распаковать в `raw.jsonl` рядом со скриптами.
- `analyze.py`: чистка (города, магазины, коммерческие, другие значения слов, тема fanline) и сверка со статьями сайта.
- `plan_xlsx.py`: контент-план по темам, собирает `podskazki-plan-statey.xlsx`.
- `proverit-v-wordstat.txt`: 101 главная фраза по темам плана для Вордстата (составлен вручную).
- `prompt-claude-chrome-wordstat.md`: промпт для Claude в Chrome со списком: частоты и выгрузка «Топ запросов» по каждой фразе.

«Вес темы» в плане считается по позиции и повторяемости фраз в подсказках. Это не частота запросов.
