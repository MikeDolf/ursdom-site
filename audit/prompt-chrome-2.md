# Промпт для Claude in Chrome: данные, которых нет у меня

Скопировать целиком в Claude in Chrome. Рассчитано примерно на полтора часа.
Результат забрать одним markdown-файлом и передать в сессию Claude Code.

**Важно про формат.** Этот отчёт будет разбирать другая модель, а не человек.
Поэтому: таблицы вместо прозы, точные числа вместо «много» и «мало»,
дословные цитаты вместо пересказа. Если данных нет, пишите ровно
«не найдено» и идите дальше. Не додумывайте и не округляйте на глаз.

---

## Контекст

Сайт: **ursdom.ru**, коммерческий раздел **ursdom.ru/dostavka/** —
доставка нерудных материалов по Екатеринбургу и Свердловской области,
бренд «Щебень-Урал». Разделу шестнадцать дней, 65 страниц.
Владелец говорит, что страницы находятся примерно на седьмой странице выдачи.

Что уже разбиралось и повторно не нужно: структура сайтов конкурентов,
их ассортимент, их H1 и H2, их микроразметка. Это я уже получил.

Сейчас нужны данные, которые нельзя увидеть со стороны: панели вебмастера,
фактические позиции, источники ссылок и реальные цены.

---

## Часть 1. Яндекс Вебмастер

Откройте **webmaster.yandex.ru**, выберите сайт ursdom.ru.
Владелец залогинен, доступ есть. Пройдите по разделам и выпишите:

**1.1. Региональность.** Информация о сайте → Региональность.
Какой регион выставлен? Если не выставлен — так и напишите.
Это самый важный пункт всей части.

**1.2. Индексирование.** Индексирование → Страницы в поиске.
- Сколько страниц в поиске всего
- Сколько исключено и по каким причинам (перечислить причины с числами)
- Есть ли среди исключённых адреса, начинающиеся с `/dostavka/`
- Отдельно: сколько адресов `/dostavka/` в поиске

**1.3. Обход.** Индексирование → Статистика обхода.
Сколько страниц робот обошёл за последние две недели, есть ли ошибки
и коды ответа кроме 200.

**1.4. Запросы.** Поисковые запросы → Управление группами / Все запросы,
период «последние 28 дней».
Выгрузите таблицу: запрос, показы, клики, CTR, средняя позиция.
Нужны **все** строки, где показов больше нуля, а не топ-10.
Отдельно пометьте строки, где в запросе есть слово «щебень», «песок»,
«отсев», «керамзит», «доставка», «купить», «цена».

**1.5. Качество сайта.** Есть ли значение ИКС, какое.
Диагностика → есть ли активные проблемы, перечислить дословно.

**1.6. Ссылки.** Ссылки → Внешние ссылки.
Сколько ссылающихся сайтов, перечислить домены.

## Часть 2. Фактические позиции

Откройте Яндекс, **поставьте регион Екатеринбург** (внизу выдачи или
в настройках) и проверьте позиции ursdom.ru по каждому запросу.
Считайте только органику, рекламу пропускайте, но фиксируйте отдельно.
Смотрите до пятой страницы включительно; если сайта нет — пишите «>50».

Проверьте эти запросы:

| Запрос |
|---|
| доставка щебня екатеринбург |
| купить щебень в екатеринбурге с доставкой |
| щебень 20 40 цена за 1 м3 с доставкой екатеринбург |
| доставка песка екатеринбург |
| куб щебня с доставкой в екатеринбурге цена |
| щебень нижний тагил |
| щебень купить в первоуральске |
| щебень новоуральск |
| отсев купить в реже |
| керамзит купить в екатеринбурге |
| сколько весит куб щебня |
| коэффициент уплотнения щебня |
| пропорции цемента песка и щебня для бетона |
| чем отличается щебень от гравия |
| сколько кубов щебня в камазе |

Для каждого запроса дайте: позиция ursdom.ru, и кто стоит на первых
трёх местах органики.

**Отдельно важно.** Последние пять запросов информационные. Если по ним
позиции сильно лучше, чем по первым десяти, это подтверждает мою гипотезу,
и я хочу видеть цифру, а не общее впечатление.

## Часть 4. Яндекс Бизнес: какой уровень карточки нужен

В Яндекс Картах найдите по запросу **«доставка щебня»** с центром
на Екатеринбурге первые 10 карточек. Для каждой:

| Название | Рейтинг | Отзывов | Фото, шт | Заполнены услуги | Есть сайт | Категория |
|---|---|---|---|---|---|---|

Отдельно ответьте:
- Какой минимальный рейтинг и число отзывов у карточек, попадающих
  в первую тройку врезки на выдаче
- Указывают ли эти компании физический адрес или работают «по региону»
- Есть ли среди них компании без офиса, только с зоной обслуживания

Последний вопрос критичен: у владельца может не быть адреса, и мне надо
понимать, реально ли попасть в локальную выдачу без него.

## Часть 5. Откуда конкуренты берут ссылки

Возьмите **три домена**, которые в части 2 чаще всего оказались в топ-3.
Для каждого найдите, где на него ссылаются. Способы:
- Запрос в Яндексе и Google: `"домен.ru" -site:домен.ru`
- Поиск названия компании в кавычках
- Проверьте профильные каталоги вручную: Пульс цен, Тиу, Флагма,
  Строительный портал Урала, 2ГИС, Яндекс Бизнес, Авито, Профи,
  региональные форумы застройщиков (например forum.ekamama, e1.ru форум)

Верните таблицу:

| Площадка | Тип | Бесплатно ли размещение | Сколько из 3 конкурентов там есть | Ссылка активная или nofollow |
|---|---|---|---|---|

Это мне нужно, чтобы составить список площадок для размещения.
Приоритет — бесплатные и с активной ссылкой.

## Часть 7. Проверка наших страниц вживую

Откройте эти адреса и посмотрите на них как обычный посетитель,
на компьютере и в мобильном виде (Ctrl+Shift+M в DevTools, iPhone 14):

- https://ursdom.ru/dostavka/
- https://ursdom.ru/dostavka/shcheben/
- https://ursdom.ru/dostavka/shcheben/rezh/
- https://ursdom.ru/dostavka/keramzit/
- https://ursdom.ru/dostavka/stati/koefficient-uplotneniya/

По каждой ответьте:
- Есть ли визуальные дефекты: наезжающий текст, горизонтальная прокрутка,
  нечитаемые цвета, обрезанные таблицы
- Открывается ли всплывающее окно связи при прокрутке, не мешает ли
- Работает ли кнопка «Написать в MAX»
- Есть ли ошибки в консоли браузера (F12 → Console), выписать дословно
- Что видно на первом экране без прокрутки на телефоне

Затем прогоните **https://ursdom.ru/dostavka/shcheben/rezh/** через
PageSpeed Insights (pagespeed.web.dev) и дайте четыре числа
для мобильной версии: Performance, LCP, CLS, INP.
Для сравнения прогоните там же главную страницу конкурента из топ-1.

## Часть 8. Хвост прошлого отчёта

Прошлый разбор конкурентов оборвался на разделе 6. Не хватает трёх:

**7. Слабые места конкурентов.** Где у них пустой текст, где нет цен,
где нет ответов на очевидные вопросы, где сайт неудобен. С адресами страниц.

**8. Яндекс Бизнес.** Закрывается частью 4 этого промпта.

**9. Что делать в первую очередь.** Не больше семи пунктов,
отсортированных по отношению пользы к трудозатратам.

Если черновик сохранился — просто пришлите эти три раздела.
Если нет — соберите заново по трём доменам из топа.

## Чего делать не надо

- Не пересказывать своими словами то, что можно дать таблицей
- Не оценивать сайты словами «современный», «удобный», «качественный»
- Не считать рекламные блоки органической выдачей
- Не заходить в разделы Вебмастера, где можно что-то изменить:
  только смотреть и выписывать
- Не выдумывать цифры, которых не увидели. Пустая ячейка полезнее
  придуманной
