# Регион: Екатеринбург и Свердловская область.
#
# ПРАВИЛА, которые тут соблюдены:
#  1. Хвосты (купить, цена, доставка, недорого, заказать, м3) в затравку
#     НЕ пишем: Букварикс раскроет их сам, а с хвостом сузит выдачу.
#  2. Ось 2 гео-нейтральная. Отсутствие города во фразе не значит
#     отсутствия регионального спроса: умножайте объём на долю области
#     (для Свердловской ориентировочно 2,9 процента от РФ).
#  3. Органических слов (чернозём, торф, перегной, земля, навоз) здесь
#     НЕТ намеренно: это тема другого проекта, пересечение тем создаёт
#     риск аффилиат-фильтра. Не добавляйте их сюда.
#
# ПОРЯДОК РАБОТЫ В БУКВАРИКСЕ:
#  1. Грузим по одной оси за раз, чтобы потом не путать источник.
#  2. Минус-слова на выгрузке: авито, юла, работа, вакансии, бу, б/у,
#     своими руками, реферат, гост скачать, майнкрафт, игра, сонник,
#     а также чужие города за пределами области.
#  3. Выгрузку сводим в один файл, дедуплицируем по нормальной форме.
#  4. Частоту берём общую (Букварикс даёт по РФ), затем прогоняем
#     отобранное ядро через Мутаген на конкуренцию и уточнённую частоту.
#  5. Порог для новой страницы: конкуренция по Мутагену не выше 5
#     и хотя бы 30 показов в месяц по региону, иначе слово идёт
#     в текст существующей страницы, а не в новую.
#
# Города разбиты на три группы:
#  A - есть страница на сайте (18)
#  B - есть в карте городов, страницы нет (3)
#  C - дальнее плечо, спрос не мерили, собираем на проверку (18)
