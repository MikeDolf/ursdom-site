# Проверка отрисовки

`audit/_verify.py` читает разметку. Есть класс дефектов, который так
не ловится: цвет буквы приходит от одного правила, фон под ней — от предка,
и результат виден только после отрисовки. Так на сайт уехала кнопка
«Узнать цену с доставкой» в тёмном блоке-призыве: контраст 1,13,
то есть тёмные буквы по тёмной стали. Читая CSS, это не увидеть.

`audit/_ui_audit.mjs` открывает все 66 страниц в настоящем браузере
и считает по факту отрисовки:

- контраст каждого текстового узла против реального фона (поднимаясь
  по предкам до первой непрозрачной заливки), включая плейсхолдеры;
- фактический кегль: ниже 12px на этом сайте не допускается, аудитория
  смотрит на телефоне на улице;
- размер цели нажатия: 44px для ссылок и кнопок, 24px для галки
  по WCAG 2.5.8;
- горизонтальный вылет за экран;
- одинаковую высоту кнопок в одном ряду;
- что оба наших шрифта действительно загрузились, а не подменились
  системными.

## Запуск

    python3 -m http.server 8899 --directory . &
    python3 -c "import json,pathlib; json.dump(sorted('/'+str(p.parent)+'/' for p in pathlib.Path('dostavka').rglob('index.html')), open('/tmp/urls.json','w'))"
    node audit/_ui_audit.mjs /tmp/urls.json mob
    node audit/_ui_audit.mjs /tmp/urls.json desk

Пустой вывод означает, что замечаний нет.

Нужен playwright и chromium. Правило проекта в силе и здесь: новая
проверка подтверждается повторным внесением бага, который она ловит.
Три поправки в проверке целей нажатия появились после ложных
срабатываний и описаны прямо в коде: проверка, которая кричит
на здоровом месте, перестаёт читаться.

## Поведение страниц и ссылки по всему сайту

`audit/_review.mjs` проходит те же страницы на телефоне (390) и компьютере
(1440) и проверяет то, что ломается при работе со страницей:

- ошибки JavaScript и запросы своего домена с ответом 4xx/5xx;
- битые картинки после прокрутки (ленивые успевают загрузиться);
- горизонтальная прокрутка всей страницы;
- калькулятор: смена объёма и города (с другим плечом) меняет итог,
  в итоге нет NaN;
- форма заявки: без телефона и согласия не проходит, заполненная проходит,
  кнопка и адрес отправки на месте. Форма не отправляется;
- частые вопросы раскрываются, «показать ещё» открывает скрытые;
- переход к форме по якорю не прячет её под липкую шапку.

`audit/_links.py` читает все страницы репозитория, включая НАШДОМ,
и проверяет внутренние ссылки, якоря, файлы картинок и скриптов,
rel="noopener" у ссылок в новую вкладку.

    python3 audit/_links.py
    node audit/_review.mjs /tmp/urls.json mob
    node audit/_review.mjs /tmp/urls.json desk

Проектный playwright может ждать другую сборку браузера, поэтому
обе браузерные проверки запускают системный chromium
(/opt/pw-browsers/chromium, путь меняется переменной PW_CHROME).
Страница-заглушка /stati/kombinirovannye-doma-plyusy-i-minusy/ уходит
по meta refresh на главную: её из списка исключают.
